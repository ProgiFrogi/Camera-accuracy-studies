# Camera-accuracy-studies
Investigation of how the accuracy of recognizing object positions on the camera changes under physical influences

## Original task:
Камеры закреплены не очень надежно на штативах, и их положение относительно поля постоянно дрейвует,
необходимо постоянно обновлять положения камер отностильно поля используя фичи на поле, например, круг,
углы, разметку и т.п. В рамках первой итерации можно расставить на поле маркеры и высчитывать положения
камеры по ним используя их как фичи для pnp. Также возможны эсперименты с подачей фичей в pnp. В
рамках этого направления необходимо будет сначало написать offline решение, высчитывающее положение
камеры относительно центра поля с GUI интерфейсом с использованием маркеров. После чего необходимо
будет заняться детекцией и фильтрацией фич на поле и pnp задачей. В ходе работы придется много работать
с камерами, заниматься их калибровкой и настраивать пайплайн зрения. GPU эксперименты приветвуются.
